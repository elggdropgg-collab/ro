# FODDER

> *Они идут первыми. Вы — последними.*
> *They go first. You go last.*

**FODDER** — кооперативный хоррор для Roblox на 1–6 игроков с элементами RTS.
Ваш состав застрял на линии, с которой не возвращаются. На каждой станции нужно найти
дизель, чтобы ехать дальше. Вместо вас в темноту идёт отряд бойцов — пушечное мясо, которым
командует один из игроков через тактическую карту. Бойцы умирают первыми. Потом — вы.

На конечной в бункере есть портал домой. Чтобы его запустить, нужно найти предохранители
и продержаться, пока он заряжается.

---

## Что внутри

| | |
|---|---|
| **Процедурные станции** | Каждый рейс — новая карта с логичной планировкой: дороги ведут от состава к ферме, амбару, вышкам; топливо разложено так, чтобы рядом его было мало, а основная часть — далеко в поле. |
| **Поезд — штаб** | Единственное безопасное место. Тактический стол, терминал улучшений, найм бойцов, ящик с патронами, рация снабжения. |
| **Отряд** | Общий на всех. Командир выбирается голосованием и передаётся при гибели. Приказы: за мной, маршрут (рисуется пальцем/мышью по карте), прочёсывать, сбор, стоять, отступить, воскресить. |
| **Бессмертные** | У каждой станции есть тварь, которую нельзя убить — только оглушить. На конечной все они возвращаются, и там их убить можно. |
| **Смерть** | Жетон павшего остаётся на месте гибели. Его можно отнести к реаниматору (их несколько на станции). Бойцы делают это по приказу — или сами, если в живых не осталось игроков. |
| **Звук** | Многослойные «рецепты» смерти: удивление → мольба → пик боли → крик, обрезанный хрустом → захлёб → тишина → *оно всё ещё ест*. Далёкие смерти слышны через рацию. Подробности: [docs/SOUND_DESIGN.md](docs/SOUND_DESIGN.md). |
| **Картинка** | Современное освещение (Future), туман, лучи — и поверх этого эффект старой плёнки: зерно, строки развёртки, полоса трекинга, разрывы при страхе. |
| **Трупы** | Скрыты помехами плёнки, но силуэт — рёбра, позвоночник, кровь — читается. Свежее тело (первую минуту) пульсирует и истекает кровью даже под помехами. Степень скрытия настраивается одним числом. |
| **Честная монетизация** | Покупки помогают, но не проходят игру за вас. Отряд зачистки — только на конечной, и твари отвечают своим подкреплением. Скример команде — с перезарядкой, а после него жертв преследуют шёпоты и шаги. |

## Документы

- [docs/GDD.md](docs/GDD.md) — полный дизайн игры: цикл рейса, станции, монстры, отряд, экономика, монетизация.
- [docs/SOUND_DESIGN.md](docs/SOUND_DESIGN.md) — анализ криков, хрустов и мучений: из чего состоит страшная смерть, как её записать и собрать.
- [docs/SETUP.md](docs/SETUP.md) — как запустить проект в Roblox Studio, загрузить звуки и создать товары.

## Структура проекта

```
src/
  shared/            ReplicatedStorage.Shared — общие конфиги, строки RU/EN, состояние матча, сеть
    Config/          Game, Squad, Monsters, Resources, Weapons, Products, Sounds, Visuals
  server/            ServerScriptService.Server
    Services/        Match, Location, Train, Squad, Monster, Combat, Revive, Commander, Audio, Corpse, Data, Monetization…
    World/           генератор: Builder, Placement, Locations/{Lobby, Field, Finale}
    Monsters/        модели и поведение тварей
    Squad/           солдаты: модель, мозг, анимация
  client/            StarterPlayerScripts.Client
    Controllers/     HUD, меню, карта, звук, плёнка, трупы, монстры, смерть, ввод…
    UI/Theme.luau    визуальный язык интерфейса (досье + полевая рация)
```

Все игровые числа — в `src/shared/Config`. Тексты — в `src/shared/Strings.luau`.

## Ветки

- `main` — итоговая, стабильная версия.
- Работа ведётся в отдельных ветках (`feature/...`) и попадает в `main` через pull request после проверки.

## Статус

Ранняя сборка: первая станция «Полевая» (пшеничное поле, Пугало и Колосники) и конечная (ночное поле, бункер, портал).
Звуки и арт-ассеты подключаются через конфиги (см. SETUP) — до загрузки игра работает с пустыми слотами звука и процедурными моделями.
